## デスクトップでの準備
1. **Unity 6000.3.22f1 を入れる。** C3_shogi は 6000.3.3f1 なので、デスクトップにはまだ入っていないかもしれない。Unity Hub の「インストール」で 6000.3.22f1 を選ぶ。違う版で開くとアップグレードの確認が出るので、必ず同じ版で開く。
2. **改行を LF にする設定をつけて clone する。** ノート PC ではリポジトリの設定を `core.autocrlf=false`・`core.eol=lf` にしていた。この設定は clone しても付いてこないので、clone のときに付ける。置き場所は C3_shogi と並べる（例：`C:\Users\<ユーザー名>\unity\C3TD`）。

   ```bash
   git clone -c core.autocrlf=false -c core.eol=lf https://github.com/bututetu1-stack/C3TD.git
   ```

3. Unity Hub の「追加」で C3TD のフォルダを選び、6000.3.22f1 で開く。初めて開くときは `Library` を作るので数分かかる。Unity MCP のパッケージ `jp.shiranui-isuzu.unity-mcp` は GitHub から取ってくるので、ネットと git が要る（ノート PC では 4.4.2。`Packages/packages-lock.json` の hash は 7647bca）。
4. `Assets/Scenes/Boot.unity` を開く。シーンには `GameBootstrap` が1つあるだけで、ほかは実行時にコードで作る。
5. **Game ビューを設定し直す**（`UserSettings` は git に入らないため）。16:9、Low Resolution Aspect Ratios はオフ、Play Maximized にする。ノート PC は表示倍率 150% で Game ビューが小さかったための設定なので、デスクトップの画面に合わせて変えてよい。
6. **`isuzu-unity-cli` を確かめる。** デスクトップには C3_shogi で入れたものがあるはず。
   - `isuzu-unity-cli doctor` で版と状態を見る。ノート PC は 4.4.2。
   - CLI とパッケージは同じ版で出る。ずれていたら `isuzu-unity-cli update` で CLI と各プロジェクトのパッケージを最新にする。C3TD の `Packages/packages-lock.json` が変わるので、変わったらコミットする。
   - C3_shogi と C3TD のエディタを両方開いているときは `--project` で選ぶ。名前は `isuzu-unity-cli projects` で分かる。
7. **動くか確かめる。**
   - `isuzu-unity-cli verify` でコンパイルのエラーが0件か見る。
   - 再生して、タイトル → 作戦選択 → 編成 → 1-1 と進み、配置して戦えるか見る。
   - 自動で戦わせるバランスの確かめは、`docs/snippets/README.md` の「バランスの確かめ」の節にある。
8. オーナーが素材を置いていないか `git status` で見る。素材は `Assets/Resources/Art`・`Assets/Resources/Audio` に直接置かれる。
