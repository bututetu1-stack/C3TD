## 6. 作業のしかた（Claude 向け）

- **エディタ**：`isuzu-unity-cli verify`（コンパイル）、`call play_mode_play --paused` → `call play_mode_step --seconds N`（背面だと時間が進まないので、自分で進める）→ `call execute_code --file X.cs` → `call play_mode_stop`。**コンパイルの前に再生を止める**。外から JSON や画像を足したら `AssetDatabase.Refresh()`。
- **確かめの道具**：`docs/snippets/tools/`（セーブの退避と戻し・画面の撮影・自動で戦わせる・ガチャの演出・ブラウザ版のビルド）。使い方は `docs/snippets/README.md` の先頭。
- **バランス**：`AutoPilot`（上手な置き方／初めて遊ぶ人のまね）と `BalanceRun`。強化・育成・ドロップ・任務は BalanceRun の間は効かない（`Upgrades.Enabled`）。目安と結果の表は `docs/snippets/README.md`。
- **ブラウザ版**：`tools/webbuild.cs` を `execute_code --wait-timeout 1800` で背面に（2〜4 分）。作るとエディタの向き先は WebGL のままになる。
- **絵を作る**：オーナーのブラウザ（Brave、Claude in Chrome でつながる）の ChatGPT。手順と自動化（`chatgpt/queue.js`・`fetch_one.sh`）は `docs/snippets/README.md` の「ChatGPT で絵を作る」。文言は素材依頼帳 https://claude.ai/artifact/GQmWJRGEXxumur5f64Mfoo （元は `docs/art-requests.html`。直したら同じ URL に出し直す）。
- **スマホ**：エディタでは `UIFactory.SetZoom(1.35f)` と `tools/snap.sh OUT.png phone` で確かめる。

### ハマりどころ（このプロジェクトで実際にあったこと）
- 同梱のフォントにない記号（全角の「－」、「✓」など）は、エディタでは出るがブラウザ版では □ になる。
- UI Toolkit：出したばかりの要素はまだ大きさが決まっていない（`layout` が NaN）。いつも出ている親から読む。USS は `:last-child` が使えない。同じ強さのセレクタは**ファイルの後ろが勝つ**。`style.display` をコードで付けると、USS の `display: none` より強い。
- 「ドメインのリロードなし」にすると 2 回目の再生から文字が消える（いまの設定のままにする）。
- bash の `node -e "…"` にバッククォートを書くとシェルに食われる。長い書き換えは .js ファイルを書いてから流す。
- コンパイル直後に再生すると数秒止まり、その間のエラーが出ることがある（続けて出なければ気にしない）。
- 素材依頼帳の JS は、カードの区切りのカンマが 1 つ抜けるとページ全体のカードが消える（10/14〜10/15 に実際にそうなっていた）。直したら `new Function(script)` で構文だけ確かめる。
